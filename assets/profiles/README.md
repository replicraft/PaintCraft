# Shared color profiles

`sRGB2014.icc` is the unchanged ICC-owned version 2 sRGB profile, revised in
February 2015. It declares PaintCraft's existing encoded-sRGB document samples;
it does not convert or replace their RGB values.

- Source: https://registry.color.org/rgb-registry/profiles/sRGB2014.icc
- Profile description: https://registry.color.org/rgb-registry/srgbprofiles
- Downloaded: 2026-10-26; 3,024 bytes.
- SHA-256: `384b832de3412066743b52a75ee906b6fb9fb8d9e09e936fc2c43223815c6e0a`.
- Copyright: International Color Consortium, 2015, retained inside the profile.

ICC permits copying, distribution and embedding of this profile without a fee.
Modified profiles must remove the original identification/copyright information
and must not be presented as the original. PaintCraft embeds these exact bytes,
without modification. See the [official profile licensing terms](https://registry.color.org/profile-library/).
