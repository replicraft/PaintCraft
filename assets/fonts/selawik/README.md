# Selawik

Unmodified Regular TrueType font from Microsoft's Selawik 1.01 release:
https://github.com/microsoft/Selawik/releases/tag/1.01

Archive: `Selawik_Release.zip`; member: `selawk.ttf`.
SHA-256: `e9d98518d8ac2817782a9a382430463a2e0793ea68350b695bb727d9a830ee1c`

Copyright Microsoft Corporation. Distributed under the SIL Open Font License
1.1; see LICENSE.txt. Embedded for interface text; the document text tool has
its own rasterization contract.

The unmodified Bold member `selawkb.ttf` from the same 1.01 archive is also
bundled for document text. SHA-256:
`f0db5e174a90e0956ad7d2844bdca1d5e6da92ec65b2c04e57ba9b180668c904`.
The same copyright and OFL notice apply. UI chrome still installs Regular;
document glyphs resolve the requested weight through Cosmic Text/Swash.
