# Batch v1 conformance vectors

Portable replay scripts for `paintcraft.batch/v1` under `paintcraft.core/default-v1`.
`*.json` files follow `paintcraft.conformance/v1`; `minimal.pcnd` is the canonical
2×2 specimen that the writer must reproduce byte for byte.

They were generated by the Python reference oracle of the PaintCraft v5.1
specification pack (`scripts/conformance_vectors.py`; the pack is reference material
kept outside version control). Do not edit them by hand. Regenerate them there when a
semantic rule intentionally changes, and review the diff.

## Replaying a vector

1. Create the initial document from `initial.new` (width, height, background colour or
   `null` for the zero-layer default, seed, policy) with deterministic identifiers.
2. Execute `steps` in order against one session:
   - `apply`: submit `batch`; compare the receipt with `expect`. Errors compare `schema`,
     `committed`, `code` and `operation_index`; `message` is omitted.
   - `undo` / `redo`: compare `state_id`, `publication_epoch`, `history_id`, or that the
     action is unavailable when `expect` is `{"available": false}`.
   - `mark-saved`: record the current StateId as the saved state.
   - `check`: compare dirty state, the selection projection, the document snapshot, the
     SHA-256 of the flat render (straight RGBA8, canvas-sized, row-major) and the SHA-256
     of the canonical PCND bytes.

Replayed by `crates/editing/paintcraft-editor/tests/conformance.rs` (everything except the PCND
digest) and `crates/services/paintcraft-formats/tests/conformance.rs` (PCND digests).
