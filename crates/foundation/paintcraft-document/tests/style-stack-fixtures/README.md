# Independent style-stack framing fixtures

These 15 independently serialized frames pin the proposed `paintcraft.layer-style-stack/v1` digest domain, ordered stable nonnil UUIDs, enablement, separate style profile and five semantic Color Overlay bytes. They were generated and frozen before the Rust candidate was authored. Five generator negatives check nil/duplicate/count/mode/byte refusal. The repeated zero-opacity Normal frame is deliberately identical to the parameter-change frame; it is not an additional independent semantic input.

`python3 generate.py --check` verifies the JSON using only Python's standard library. It does not invoke Rust or validate a PCND writer, renderer, budget owner, history or frontend. This is standalone vocabulary only; no Layer style field or runtime capability has been added.
