# Independent proposed Curves numerical specification

This is a planning oracle, not a registered or shipped PaintCraft profile. Input is exactly five output bytes at fixed encoded-byte input positions0,64,128,192,255. Default is identity0,64,128,192,255. Outputs are free, endpoints unlocked; no monotonicity constraint or slope limiter.

For knot j, its derivative is the exact rational secant between knots max(j−1,0) and min(j+1,4). For each adjacent interval, find the unique cubic polynomial P(n)=a+b*n+c*n²+e*n³ satisfying the two endpoint values and endpoint derivatives. The independent generator solves this four-by-four system by Fraction Gaussian elimination, then evaluates by Horner. It does not call a product kernel or use the proposed product Hermite-basis implementation to supply expected values.

Select intervals[0,64),[64,128),[128,192),[192,255], with finalwidth63 and penultimate centered-secant denominator127. Evaluate at each integer byte input, clip the exact rational result to0..255, then round once nearest with exact halves upward. Alpha is unchanged. Apply the same resulting byte LUT independently to straight encoded RGB, including hidden RGB beneath alpha0. Identity preserves hidden RGBA exactly.

Each mask is applied once after candidate rounding, using `(incoming*(255−m)+candidate*m+127)//255` on RGB; alpha remains incoming. Coverage0 copies incoming,255 candidate. No alpha-aware spatial blend or interpolation of curve parameters.

The oracle stores64 ordered profiles:32 binary-output vertices,8 named structural profiles and24 seed-controlled profiles. Each full LUT contributes256 bytes to the aggregate SHA256, in profile order. Per-profile literals include all knot boundaries and adjacent bytes. Twelve exact un-clipped half ties are independently found in that enumeration. For eight named profiles ×three RGB tuples ×six coverages(0,1,127,128,254,255), each all-alpha stream contains256 RGBA records with alpha ascending0..255. Stream bytes are RGBA only; IDs/RGB/coverage/order are explicit JSON metadata. Their aggregate concatenates streams in that same order. Separate RGBA literals use alpha0,128,255.

A finite integer-bound experiment enumerates all32 extreme output vertices and all256 input bytes for a stated common-denominator Hermite evaluation order. Every parameter-dependent term/product/partial sum is affine in the five output values. Its extrema over the entire continuous output cube therefore occur at vertices. Parameter-independent basis terms are enumerated directly. Clipping and the positive rounding-numerator operation are monotone, so their extrema follow the same endpoints. This proves arithmetic bounds for that explicit order, not arbitrary reassociation or an unimplemented compiler. It does not establish runtime performance or any product resource quote.

Invalid arrays and lexical controls are proposed data only. Final public parameter names/schema are not registered. Proposed strict bytes reject bool/float/coercion/default, fraction/exponent spelling, wrong length, missing/extra data and out-of-range values. Signed-zero lexical acceptance is undecided; existing unrelated readers are unchanged.
