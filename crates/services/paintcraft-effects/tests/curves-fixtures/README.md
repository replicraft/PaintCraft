# Curves independent numerical fixtures

This finite fixture was mechanically copied from the independently frozen planning oracle at `docs/validation/curves-planning`. The generator, specification and oracle JSON retain those exact bytes. It supplies expected numerical data for a standalone compiler foundation; it makes no UI, wire-parser, descriptor, registry, execution-worker or compatibility claim.

Run `python3 -B generate.py` to verify exact frozen JSON bytes. `--write` regenerates from the standalone stdlib reference. No product source, compiler output, product imports or expected-kernel calls enter the generator. LUT expectations come from Fraction Gaussian elimination of each segment's endpoint/value/derivative constraints and Horner evaluation, independently of the product Hermite-basis implementation.

The corpus has64 full256-byte LUTs:32 binary-output vertices,8 named structural profiles and24 deterministic seeded profiles. Each full LUT has an independent SHA256; the aggregate concatenates all64 LUTs in JSON order. Twelve literal exact half ties,432 RGBA/mask literals and144 all-alpha streams (36,864 records) supplement those hashes. Each all-alpha stream hashes RGBA with alpha ascending0..255; aggregate stream order is exactly JSON array order. This is not exhaustive numerical qualification over the2^40 five-byte parameter domain. See `specification.md` for knots, endpoint slopes, rounding and framing.

The separate integer-intermediate bound is stronger in a different scope: for its explicitly stated basis multiplication/sum/rounding order, all parameter-dependent pre-clamp intermediates are affine in the five outputs. Their extrema on the full continuous byte-output cube occur among the32 vertices, enumerated at all256 input positions. Clipping/positive rounding operands are monotone. Every one of8192 integer results was also checked against the independent Fraction solver. The largest absolute recorded intermediate is2,194,728,288,256 (<2^41;42 signed bits), so checked i64 suffices for that specified order. This bound does not prove arbitrary reassociation, compiler resource accounting, cancellation, performance or an implementation that has not been tested against the fixture.

The invalid arrays and fractional/exponent JSON controls remain data. Final catalog/public-parser semantics are not established by this standalone foundation; no product parser is called for them. Signed-zero lexical acceptance is explicitly undecided in the proposed specification. Alpha is preserved while hidden straight RGB is mapped; masks mix once after candidate byte rounding using the existing point-coverage policy.
