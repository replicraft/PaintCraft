This independent UI-only PCND3 specimen has one enabled, unmasked identity
Black & White strength-zero prefix and two opaque red/green samples. It has no
source metadata. The default output of each of the four new algorithms changes
the source and gives two distinct colors, allowing a literal screenshot marker.

`python3 generate.py` verifies the authored PCND and manifest byte for byte.
`python3 generate.py --write` deliberately regenerates them using Python stdlib
byte framing, SHA-256, and independent exact Fraction arithmetic. No PaintCraft
writer or evaluator is imported. New browser execution remains separately
qualified; generation and Node checks alone do not establish runtime support.

This folder is separate from the 29 PCND point-registry fixtures and does not
change their hashes, numerical planes, identities, or historical receipts.
