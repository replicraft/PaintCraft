# Neutral OpenRaster group conversion fixtures

These owned fixtures are generated with Python's standard library. `generate.py` writes ZIP/XML and minimal RGBA8 PNG members; an independent `Fraction` calculation produces the expected flat pixels, rounding after each leaf according to PaintCraft's existing encoded RGBA8 composition policy. No PaintCraft parser, serializer, renderer or external application generates the expected results. `oracle.json` records every archive/raw-image hash and effective leaf properties.

`neutral.ora` has explicit neutral `auto` groups, nested and empty groups, duplicate/Unicode group names, hidden ancestry, individually hidden children, overlapping partial-alpha pixels, hidden RGB, negative leaf offsets and a partly outside foreground. `flat.ora` represents the same ordered leaf operations and effective visibility. Exact raw pixels and composition are checked independently; the conversion does not add a group buffer or another rounding step.

The separate `project_import::decode_ora_with_neutral_groups` entrypoint implements this explicit converted-copy subset. It requires group opacity omitted or expressed as `1` or `1.` followed by one or more zero digits. This intentionally excludes equivalent exponent or leading-zero forms, and rejects near-one decimals even if binary floating-point parsing would round them to one. Every admitted group requires explicit `isolation="auto"`; root-stack attributes remain forbidden. Unknown or unsupported semantics remain refused even when hidden.

Conversion reports `ora-group-structure-not-retained`: group hierarchy, names and separate group visibility controls are not saved into the flat PCND document. The current ancestor visibility is applied to each editable leaf. Original child visibility under hidden ancestry is therefore not claimed preserved. Leaf offsets do not acquire group translations. Group x/y, isolated or default-isolated groups, nonneutral group opacity, other blends and unknown elements remain outside this profile.

`different-projection.ora` contains a well-formed but different merged PNG. It is refused as an unsupported rendering/projection profile, not labelled archive corruption. `policy-before-pixels.ora` combines an unsupported group with invalid PNG payloads to prove classification precedes pixel decoding. Additional fixtures cover hidden unsupported nodes, near-one opacity and a thumbnail larger than the canvas. Unit tests price retained merged/render/thumbnail buffers before their pixel allocation, and separately bound all tree nodes, depth and group names.

Ordinary `ora::decode_layers`, `project_import::decode_ora` and generic layered dispatch still reject groups. The exact `ora-neutral-auto-flat-copy-v1` variant is reserved for explicit Studio Import; ordinary Open, Classic and preserving Save remain unavailable. Group conversion requires the actual group-structure loss acknowledgement, translated in all seven catalogs. Existing flat imports retain their prior losses and deterministic document identities. Legacy CLI/MCP stream snapshots select the old strict flat profile before decoding and refuse groups. This does not provide editable hierarchy or GIMP/Krita qualification.

Consumer tests cover real native EN/JA review controls, browser-host EN/JA review controls with a separate Wasm build, and actual CLI/stdio MCP processes. They check the six independent leaf records and merged pixels, hidden RGB, cancellation/stale owners/drafts, source mutation, PCND reopen, and source-alias refusal after saving and renaming. Same-descriptor regular-file capture binds native/headless review to original bytes; browser decoded results own their input-derived state. A separate headless production browser smoke uploads the real archive through Import, cancels the visible limitation review, then approves a repeated import and downloads PCND. An independent Python PCND reader checks all six source leaf hashes/properties and the Fraction-composed merged pixels, without PaintCraft decoder code. Its source/asset/tool receipts remain separate from the host tests. An optional extra browser-reopen harness timed out on menu coordinates after the valid download; that failed attempt is retained and is not counted as a reopen pass.

References: [OpenRaster 0.0.6 layer stack](https://www.openraster.org/baseline/layer-stack-spec.html) and [file layout](https://www.openraster.org/baseline/file-layout-spec.html). In particular, stack offsets never translate children; the source's valid `auto` semantics must not be confused with the default isolated behavior. Fixtures and generator are covered by PaintCraft's repository license.

The ordinary flat parser keeps its original single preallocated leaf collector. It allocates no source tree, group-frame vector or second leaf collector. A tight pre-group metadata allowance (2,397 bytes on the tested 64-bit layout; 1,217 on 32-bit) is an explicit regression control: the old flat route succeeds at that allowance, while the tree-enabled route correctly requires its own additional budget. Both paths share the XML state machine.
