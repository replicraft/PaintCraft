# Excluded mixed-build CLI prototype

Canonical outputs match byte-for-byte, but the planned CLI came from a combined
desktop/CLI build while the baseline was CLI-only. These timings are retained and
excluded from the adoption decision. The matched CPU-only follow-up records a
forced current-source rebuild and executable identities. Original exports remain
lossless in raw_exports; compact JSON has identical parsed values.

See the [matched CPU-only decision](../paint-plan-cli-cpu-2026-10-21/DECISION.md).
