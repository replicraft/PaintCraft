PaintCraft 0.2.0 adds editable filters and masks, desktop layer blending, signed updates and a Win95-inspired Retro workspace.

- **13 editable Studio filters**, including Levels, Exposure, Curves, Vibrance, Hue/Saturation, Noise and Box Blur, with live previews, saved stacks and CLI/MCP editing.
- **Saved layer and filter masks**, selection-based mask workflows and undo. Desktop Studio also supports **Normal, Multiply and Screen** layer blending.
- **Retro Win95-inspired painting** on desktop and in the browser: sixteen tool choices, a named color palette, W95FA typography and independent workspaces. Real nearest-neighbor resize/stretch and skew preserve layers or transform selected pixels, with undo and stale-source guards.
- **More capable imports:** reviewed 16-bit JPEG XL conversion, explicit TIFF page selection and orientation, and BMP RLE/RGB555/RGB565 decoding. Editing remains 8-bit RGBA.
- **Signed desktop updates** with user-initiated checks/downloads and save-before-restart coordination. Package-managed installations keep their manual/package-manager update path.
- **Packaging fixes** for Flatpak builds, consistent release-source selection, matched codec helpers and bundled license notices.

Install 0.2.0 manually when upgrading from 0.1.1 to enable signed update checks. Package-managed installations continue using their package manager.

Supported format subsets and conversion warnings remain explicit. Downloads use Minisign verification; Windows binaries are not Authenticode-signed and macOS apps are not notarized. Full install/relaunch and physical-device qualification remain platform-specific. See the [installation notes](https://github.com/replicraft/PaintCraft/blob/main/docs/RELEASING.md#platform-details).
