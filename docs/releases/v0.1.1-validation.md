# PaintCraft 0.1.1 release validation

This record covers the immutable [0.1.1 release](https://github.com/replicraft/PaintCraft/releases/tag/v0.1.1),
published on 2026-10-29 at 07:23:42 UTC. It establishes executed native packaging
and finite helper/CLI consumer checks, not completion of the roadmap's T28 or
T35 gates, original-application compatibility, or physical-device qualification.

on five targets; public V8 is selected only on Apple Silicon. This release does
not promote V8 JPEG XR writing on the held targets or change their global Cargo
feature selection.

The actual worker and installed-consumer checks cover the admitted JPEG XL,
JPEG XR, HEIF, AVIF and HDR/EXR subsets and their source/owner, consent,
cancellation and failure controls. The exact executed selectors are in
[qualify_cli_helper.py](../../scripts/packaging/qualify_cli_helper.py) and
[installed_codec_worker.rs](../../apps/paintcraft-cli/tests/installed_codec_worker.rs).
The explicit AVIF identity/SDR and HDR/EXR baseline selectors ran on every
target. Apple Silicon additionally ran public V8 portable JPEG XR goldens and
forged-export-contract controls. Those goldens retain their independent C
reference provenance; a live C oracle or an original Windows application was
not run on every release runner.

Earlier failed candidates remain failures. The final producer includes the
complete-declaration scanner correction and the runtime streaming verifier
correction, so retained linker marker constants do not masquerade as second
contracts. Duplicate, stale, malformed and truncated declarations still refuse;
hash, file-identity, manifest and resource checks remain active. Qualification
installations use a fresh runner-temporary path outside Cargo's restored cache.

## Package and download checks

- Both Windows jobs installed, repaired and uninstalled the actual MSI and
  checked owned file associations and installed payloads. They also uploaded
  portable and CLI archives. This does not test every interactive Windows UI or
  upgrade/recovery workflow. Windows executables are not Authenticode-signed.
- Both macOS jobs verified ad-hoc signatures and the DMG, mounted it read-only,
  and compared the app's files and permissions against its updater ZIP. The
  executable architectures and packaged helper layout were checked. These
  checks do not launch the desktop application. The apps are not Developer ID
  signed or notarized.
- Both Linux jobs inspected DEB/RPM contents, desktop/AppStream metadata,
  executable dependency resolution and extracted AppImage contents. This does
  not establish installation and interactive execution on every distribution,
  display server or graphics driver.

The published set contains exactly **24 platform downloads plus
`SHA256SUMS.txt`**. Assembly and publication each ran the independent
`sha256sum --check` over all 24 files; missing, extra or stale assets were refused.
A final metadata audit confirmed the exact published names and compared each
manifest hash with GitHub's uploaded-asset SHA-256 digest. Only the checksum file
was downloaded during that final audit, not every platform binary. Its downloaded
bytes also matched GitHub's digest:

```text
93c26b308490d37750cb0208a985dad17fc6ce1830eeb512fb7d5e4dbc726280  SHA256SUMS.txt
```

The public [release asset API](https://api.github.com/repos/replicraft/PaintCraft/releases/tags/v0.1.1)
and [checksum file](https://github.com/replicraft/PaintCraft/releases/download/v0.1.1/SHA256SUMS.txt)
provide the reproducible publication record. The checksum audit does not stand
in for the native execution performed by the producer jobs above.

## Remaining qualification

T28 and T35 remain partial. Security/permission probes, complete license/asset/
branding review, the full capability evidence manifest, clean-install resource
removal and recovery/upgrade lifecycles, original-application edit/resave tracks,
and broader codec/reference matrices still require their own evidence.
Physical tablet/driver testing and general native GUI/GPU device execution are
not established by headless helper tests or package inspection. Native macOS
pen capture starts automatically in this release, but Windows/Linux native pen
acquisition remains unfinished. No physical-memory, arbitrary-code sandbox,
interactive latency or historical Paint parity guarantee is inferred here.

Later source or backend changes need impact review and fresh applicable tests;
these results do not automatically qualify new profiles added after `v0.1.1`.
