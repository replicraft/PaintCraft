PaintCraft's first preview brings a familiar painting workspace to desktop, browser and command line.

- Classic with Windows 7, 10 and 11 skins, plus Studio with tabs and floating panels.
- Nine brushes, shapes, text, selections, layers and undo/redo.
- Compact PCND projects, image export, recent files and crash recovery.
- Light and dark themes in seven languages.

Downloads include desktop and CLI builds for Windows, macOS and Linux, on x64 and ARM64. Choose an MSI or portable ZIP on Windows, a DMG on macOS, or an AppImage, DEB, RPM or portable archive on Linux.

This is an early preview. Windows downloads are unsigned, and macOS downloads are not notarized. See the [installation notes](https://github.com/replicraft/paintcraft/blob/main/docs/RELEASING.md#platform-details) for details.
