PaintCraft 0.1.0 is an early preview of a familiar desktop painting app.

- Classic with Windows 7, 10 and 11 skins, plus a separate Studio workspace.
- Nine brush styles, shapes, text, selections, layers and undo/redo.
- Editable PaintCraft projects, image export, recent files and crash recovery.
- Light/dark themes and seven interface languages.

### Install

- **Windows:** choose `windows-x64` for most PCs or `windows-arm64` for an ARM PC. The MSI installs PaintCraft and registers `.pcnd` projects. For a portable copy, extract the ZIP and run `paintcraft.exe`.
- **macOS:** choose `macos-arm64` for Apple Silicon or `macos-x64` for Intel. Open the DMG and drag PaintCraft to Applications. The `-update.zip` is for updating an existing app bundle, rather than first installation.
- **Linux:** choose the package for your architecture and distribution. For AppImage, make the file executable and open it. The tar.gz is a portable archive that uses your system's graphics libraries.
- **FreeBSD:** extract `freebsd-x64.tar.gz` and run `paintcraft` in a graphical desktop with its runtime libraries installed.

These preview downloads are not Authenticode signed or Apple notarized. If macOS blocks the app because the developer cannot be verified, try opening it once, then use **System Settings → Privacy & Security → Open Anyway** for your trusted download. [Apple's instructions](https://support.apple.com/en-us/102445) explain the process. No system-wide security setting needs to be disabled.

### Start painting

1. Choose a Classic skin on first launch. You can change the skin or switch to Studio beside Settings later.
2. Brush is selected by default. Size and opacity controls sit beside the canvas.
3. Save as `.pcnd` to retain layers and project data. Use **Save as → Picture** to export PNG, BMP or JPEG.
4. Use **Settings → Appearance** for the theme and language. **Settings → About** shows the installed version.

The Windows 11 skin is the most developed presentation in this preview. Historical skins and Studio continue to improve. Custom-angle rotation, applying resize/skew, background removal, Paste and some other menu commands remain unavailable. Printing currently works on macOS only. An in-app updater is not included yet.

`SHA256SUMS.txt` covers every release download. If something goes wrong, please [report it](https://github.com/replicraft/PaintCraft/issues) with your OS, architecture, selected skin, steps to reproduce and any error details.
