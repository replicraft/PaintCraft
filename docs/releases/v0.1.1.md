PaintCraft 0.1.1 expands painting, automation and file support, with more reliable input and browser sessions.

- Paint and edit through MCP, including layers, shapes, previews and image exports.
- More Studio formats and export options, including DDS textures, historical Paint pictures, layered imports and custom brush resources. Supported subsets and conversion warnings remain explicit.
- Pen pressure controls for size and opacity, plus improved mouse, pen and touch arbitration in the browser.
- Native macOS pen capture starts automatically, with ordinary mouse input retained if capture is unavailable.
- Safer text composition and input cancellation that protects completed edits.
- More reliable browser startup, restart and canvas ownership.

Desktop and CLI downloads are available for Windows, macOS and Linux on x64 and ARM64. Use the MSI or portable ZIP on Windows, DMG on macOS, or AppImage, DEB, RPM or portable archive on Linux.

Tablet and driver behavior still needs physical-device testing. Windows and Linux native pen acquisition remains unfinished; ordinary input continues to work. This early preview is unsigned on Windows and not notarized on macOS. See the [installation notes](https://github.com/replicraft/paintcraft/blob/main/docs/RELEASING.md#platform-details).
